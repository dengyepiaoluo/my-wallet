# 我的小账本 (My Wallet)

个人记账 **安卓 App**，极简风格，数据全部保存在手机本地，不联网、不申请权限。

> ⚠️ **仅支持安卓（Android 5.0+）**，暂不支持苹果 iOS / iPadOS。

## 功能

- **记一笔**：收入 / 支出，支出可选分类（餐饮、交通、购物、居住、娱乐、医疗、学习、人情、其他）；支持今天、昨天、任意日期，可以提前记录未来的「计划账」
- **概览**：本月收入、支出、结余与支出构成一目了然；设置月预算后自动计算「已花 / 还剩 / 每天还能花多少」，超支自动标红；**存钱预测**：距春节倒计时，按「每月计划存 / 近 3 月实际 / 工资和支出」三种口径预测到过年、一年后能攒多少钱；累计结余按农历年统计，显示今年春节前的累计余额
- **主题**：8 款配色一键切换 —— 薄荷绿、樱花季、夏日海空、紫藤苑、落日黄昏，以及星夜紫、翡翠夜、夜樱三款暗色主题
- **明细**：按月分组流水，点击任意记录可编辑或删除；未来的账目标记为「计划」
- **规划**：设置每月预算、每月计划存、每月工资（可追加涨薪 / 降薪记录，自动反映到预测）、发薪日和定期账单（房租等固定收支）；支持数据导出 / 导入（剪贴板备份，方便换机）

## 下载安装

到 [Releases](../../releases) 页面下载 `wallet-v1.1.1.apk`，传到安卓手机后点击安装即可
（安装时系统提示「未知来源应用」，选择「仍要安装」）。

从 v1.0.0 升级可以直接覆盖安装，已有的记账数据和设置都会保留。

## 构建

1. 安装 Flutter 3.24+ 与 Android SDK
2. `flutter pub get`
3. 复制 `android/key.properties.example` 为 `android/key.properties`，填入你自己的签名信息
4. `flutter build apk --release`

产物：`build/app/outputs/flutter-apk/app-release.apk`

## 测试

```bash
flutter test     # 24 个用例
flutter analyze
```

## 说明

- 无后端、无账号、无网络请求，数据存储于应用私有目录（卸载即清除，记得用「导出」功能备份）
- 兼容 v1.0.0 的老数据，升级后记录与预算都会保留
- 仅供个人学习使用
